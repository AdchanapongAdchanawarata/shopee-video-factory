# ⚡ Shopee 1-Click Video Maker (Chrome Extension)

ส่วนขยาย Google Chrome สำหรับดึงข้อมูลสินค้า ชื่อจริง ราคาจริง และคลิปวิดีโอรีวิวแท้จากหน้า Shopee ส่งเข้าสู่ระบบผลิตวิดีโอ 9:16 ทันที 100%

---

## 📌 วิธีติดตั้งลงใน Google Chrome (ทำครั้งเดียวใน 20 วินาที):

1. เปิด **Google Chrome** แล้วพิมพ์ในช่องที่อยู่ URL:
   ```text
   chrome://extensions/
   ```
2. เปิดสวิตช์ **"โหมดนักพัฒนาซอฟต์แวร์" (Developer mode)** ที่มุมขวาบนของหน้าจอให้เป็นสีฟ้า
3. คลิกปุ่ม **"โหลดส่วนขยายที่คลายการบีบอัดแล้ว" (Load unpacked)** ที่มุมซ้ายบน
4. เลือกโฟลเดอร์นี้:
   ```text
   C:\Users\aaadc\OneDrive\Desktop\shopee_killer\chrome_extension
   ```
5. ติดตั้งสำเร็จทันที! คุณจะเห็นไอคอน Shopee Video Maker ขึ้นในแถบส่วนขยายของ Chrome
